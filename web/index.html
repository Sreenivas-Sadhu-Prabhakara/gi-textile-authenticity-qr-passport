The cluster's signing key

One key for the cluster, not one per piece. The public half is published so buyers can check passports; the private half signs them and never leaves the cluster.

This tool never writes a private key to its register file. Start it with -key /path/to/cluster.key to have it read the key from a file you control, or paste the key in when you issue a passport.

Generating a new key does not revoke the old one. Passports already issued verify only against the key that signed them, so keep the old public key published alongside the new one.
